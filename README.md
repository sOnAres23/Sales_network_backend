# Проект разработки Онлайн платформы торговой сети электроники и инструментов с помощью Django REST Framework ^_^


## В данном проекте реализованы модели контактов, продуктов и самой сети по продаже электроники.
Сеть представляет собой иерархическую структуру из трех уровней:

- завод;
- розничная сеть;
- индивидуальный предприниматель.

Каждое звено сети ссылается только на одного поставщика оборудования (не обязательно предыдущего по иерархии).
Важно отметить, что уровень иерархии определяется не названием звена, а отношением к остальным элементам сети, т. е. 
завод всегда находится на уровне 0, а если розничная сеть относится напрямую к заводу, минуя остальные звенья, 
ее уровень — 1.

### Также дополнена функционалом админ-панель созданных объектов.
На странице объекта сети добавлены:

  - ссылка на «Поставщика»;
  - разлчиные фильтры;
  - admin action, очищающий задолженность перед поставщиком у выбранных объектов.

### Создана документация по API:
  - swagger: http://127.0.0.1:8000/swagger/
  - redoc: http://127.0.0.1:8000/redoc/

## Установка:
1. Убедитесь, что у вас установлен Poetry. Если нет, вы можете установить его, следуя официальной документации.
2. Клонируйте репозиторий через ssh: 
```
git@github.com:sOnAres23/Sales_network_backend.git
```
3. Устанавливайте зависимости из файла **pyproject.toml** командой: 
```
poetry install
```

## Использование:
- Создайте базу данных в PostgreSQL
- Переименуйте файл .env.sample в .env и заполните его необходимыми данными
- Создайте суперпользователя(админа):
```
python manage.py csu    
```
Проект на стадии разработки, для запуска приложения протестировать работоспособность можно локально через терминал, запустив:
```
python manage.py runserver
```
После запуска приложения локальным способом, вы сможете получить доступ к нему по адресу http://127.0.0.1:8000/.
